A Monday morning punchline, written for the make.fun bounty of that
name: the week arrives like a software update nobody agreed to —
unavoidable, unexplained, installed overnight — and it has moved all
your icons. There is no changelog, there is no rollback, and Friday is
a rumour started by the calendar.

## Running it

`node main.ts` clears the output directory's contents and writes the
line to `/output/entry.txt` as plain UTF-8 text.
